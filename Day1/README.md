
# Day 1 - Project Initialization

## Objective

The objective of Day 1 was to plan the Gym Management System project, define its scope, select the technology stack, and initialize the project repository.

---

## Project Overview

The Gym Management System is a web-based application developed to simplify the management of gym operations. It enables administrators to manage members, trainers, memberships, attendance, payments, and reports efficiently through a centralized system.

---

## Technologies Selected

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Version Control
- Git
- GitHub

---

## Planned Features

- Member Registration
- Member Login
- Trainer Management
- Membership Plans
- Attendance Management
- Payment Management
- Dashboard
- Reports
- Search and Filter
- Profile Management
